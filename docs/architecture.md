# Interview Agent 架构与边界

Interview Agent 是个人面试练习与复习工具，提供资料导入、岗位配置、逐题模拟、结束复盘和基于证据的建议回答。

## 组件

- 前端：Vue 3、TypeScript、Vite；生产环境由 Nginx 提供静态文件并代理 API。
- 后端：FastAPI、Pydantic、httpx；当前按单进程、单 worker 运行。
- 存储：SQLite，保存个人档案、原文分块、向量、来源关系、岗位快照、问答和生成任务。
- 对话模型：配置为 OpenAI 兼容接口，通过后端调用。
- 向量模型：Ollama，本地默认使用 `qwen3-embedding:0.6b`、1024 维。

## 检索与证据

资料按档案隔离，保留来源标识、内容哈希和原文位置。检索融合向量、TF-IDF 与有界图扩展；向量服务不可用时回退文字检索并保存诊断。可以重建缺失向量。

引用校验拒绝本次材料之外的片段 ID；这证明来源归属，不保证模型语义推断必然正确。源码存在不能证明个人贡献，测试代码存在不能证明运行通过，实验结果也不能直接当作生产指标。

## 面试会话

会话保存本场绑定的岗位快照，区分生成中、等待回答、完成和错误。回答提交携带请求标识实现幂等；失败续办不重复插入候选人的回答。严格模拟过程中不展示建议答案，结束后才生成复盘和逐题建议回答。

## 记忆与建议回答

写入采用规则优先、模型兜底；未知类型分类失败时保守归普通内容。长期资料来自有来源的简历、项目文档、学习资料或明确补充信息。本轮问答、复盘和模型生成稿不自动提升为长期个人事实。

新面试结束时，与复盘一并持久化建议回答任务；历史面试由按钮手动入队。任务按题保存 `queued/generating/ready/error` 状态，支持失败项重试和进程重启后恢复；已完成结果保留。回答使用本轮有界上下文和长期资料检索，关联引用依据及待补信息。

外部导入的历史对话识别依赖类型元数据和标题规则，不能保证自动识别任意命名的混合文件。

## 数据和运行限制

真实配置和个人内容仅保存在本地 `.env`、`backend/.env` 和 `data/`，不得提交。Docker 镜像不包含上述文件，数据库独立持久化。模型调用会把本轮所需上下文与资料片段发送到你配置的模型服务，请按自己的资料范围选择服务。

当前没有账户登录与权限系统。`profile_id` 是数据隔离标识，不能作为身份认证；默认仅面向本机使用。扫描 PDF 的 OCR、自动联网核验、流式生成和多实例任务协调尚未实现。
